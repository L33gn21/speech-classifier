# VoxShield — Team B

### Voice Scam Detection & Speaker Analysis

A multitask model on a fine-tuned WavLM backbone produces both judgments — human vs. AI-generated, and accent profile — from a single audio clip.

🔗 **[Try it live](https://language-detector-437352311046.us-west2.run.app/)**  |  🎬 **[Demo video](https://www.youtube.com/watch?v=HXz0Fad7RcQ)**

## Executive Summary

VoxShield developed an AI service platform that detects, in real time, whether a voice is generated by AI or spoken by a real person. As voice phishing and AI-generated voice scams become increasingly common, the platform provides an effective way to identify potentially fraudulent audio. In addition, when the speaker is a real person, the system can classify the speaker's accent or country of origin. This technology can help protect the general public from voice-based fraud while also providing valuable support to law enforcement and investigative agencies. Overall, VoxShield offers a practical AI solution for enhancing voice authentication and public safety.

# VoxShield

## Service Overview

### What it does

Given a single audio clip, the service estimates two things at once:

- **Accent (nationality) estimation** — how close the speaker's English sounds to each of several accent regions, expressed as per-class probabilities. It currently covers 6 classes — **US / UK / CA / AU / IN / CN** — and reports the softmax output as "accent closeness" percentages (e.g., `US 30% · UK 45% · IN 10% · ...`).
  > **Note:** these percentages are the model's softmax confidence, not a calibrated measure of accent similarity. They can be overconfident on speakers or recording conditions unlike the training data.
- **AI synthetic speech (deepfake) detection** — for the same input, whether the clip is a real human recording (**REAL**) or generated by TTS / voice conversion (**FAKE**).

Both tasks run through a **single multitask model**: a shared WavLM backbone with a country head and a real/fake head on top, so accent estimation and authenticity detection don't require two separate models.

### Why we built it

Estimating a speaker's accent region from audio alone is a recurring need in language-learning feedback, call-center quality monitoring, and speaker profiling.

At the same time, as AI-generated synthetic speech spreads, more use cases need to verify whether audio is actually human before trusting it. Solving both problems in one pipeline is why we chose a multitask design.

### How it works

```
Audio input
   │
   ▼
Pretrained audio encoder (WavLM Base+, fine-tuned)
   │
   ├──▶ Country (accent) classification head ──▶ US/UK/CA/AU/IN/CN probabilities
   │
   └──▶ Real/fake classification head        ──▶ REAL/FAKE probabilities
```

- Training data lives in a **GCS bucket** (gcloud-first); training runs on **Vertex AI Custom Jobs** (T4 / A100). Locally we only keep source code, environment variables, and docs.
- Results can be checked directly through a **Cloud Run demo** (model tester) — upload a clip and see accent percentages plus the REAL/FAKE verdict.

### Key features

- **One backbone, two heads** — accent classification and synthetic-speech detection are trained jointly on a shared encoder, keeping inference cost low.
- **Frame-level evidence** — frame-level logits are preserved so a time-axis accent heatmap can be rendered (`infer.py --plot`).
- **Optional domain randomization augmentation** — the training pipeline can apply speed, band-limiting, reverb, and colored-noise augmentations to simulate channel/recording differences (`train.py --augment --aug-strength`); the deployed model was trained **without** augmentation.
- **Reproducible training pipeline** — curation → split → train → evaluate → deploy is fully scripted, with a report written for every experiment (`classifier/reports/`).

### Limitations

- **Accent percentages are uncalibrated.** They reflect model confidence over 6 fixed classes; a speaker from a region outside these classes is still forced into one of them.
- **Deepfake detection is trained on ASVspoof 2019 LA only**, whose spoofed audio comes from TTS and voice-conversion systems available up to 2019. Detection performance on recent voice-cloning / TTS systems is not guaranteed.

## Dataset, AI Model & References

### Dataset

This project uses the following datasets and external data sources:

- **ASVspoof 2019 LA** — The logical access (LA) partition of the ASVspoof 2019 challenge database, containing bona fide speech and spoofed speech generated by TTS and voice-conversion systems. Used to train the real/fake head. License: [ODC-BY 1.0](https://opendatacommons.org/licenses/by/1-0/). [Wang et al. (2020)]
- **GLOBE** — A high-quality English corpus with worldwide accents. Used as the main source of accent-labelled speech for the accent (country) head. License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). [Wang et al. (2024)]
- **Speech Accent Archive (SAA)** — Native and non-native English speakers, each reading the same English paragraph. Used to add speaker diversity to every accent class. License: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). [Weinberger & Kelley]

### AI Model

This project uses the following AI models for training, validation and test:

- **WavLM Base+** ([microsoft/wavlm-base-plus](https://huggingface.co/microsoft/wavlm-base-plus)) — Backbone of the deployed multitask model: a self-supervised speech encoder fine-tuned with an accent (country) head and a real/fake head. License: [CC BY-SA 3.0](https://github.com/microsoft/UniSpeech/blob/main/LICENSE) (the UniSpeech repository license linked from the model card). The HuggingFace Transformers implementation used to load it is Apache 2.0. [Chen et al. (2022)]

### License note
